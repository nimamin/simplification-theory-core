# Contributing

Thank you for your interest in Simplification Theory.

You are welcome to open GitHub issues about:
- Reproducible simulation results and discrepancies
- Scientific questions and testable predictions
- Documentation mistakes and proposed improvements
- Bug reports

**Please do not submit code pull requests or modified source files without first obtaining written permission.**

The public PolyForm Strict license does not authorize modifying or redistributing the code. Contributions involving code require a separate written agreement so the project can lawfully integrate, maintain, and commercially license the contribution.

Issue discussions do not themselves grant rights to third-party copyrighted material. Avoid posting proprietary code or confidential information.

The project maintainers may close contributions that do not comply with this policy.
